# Security policy

Report potential vulnerabilities privately to **rizy.izy15@gmail.com** with
the subject “Jotwisp security report”. Include affected versions, reproduction
steps, and impact using synthetic data. Do not attach private draft libraries,
credentials, or exploit activity against other people's systems.

The latest public release is the supported security-maintenance line once
released. Pre-release source builds are for testing; no response-time guarantee
is offered. Please allow time to investigate before public disclosure.

Jotwisp stores plain text locally, not encrypted vaults. It is not intended
for storing passwords or secrets. The App Store build has sandboxed local
storage and user-selected import/export access, with no network entitlement.
