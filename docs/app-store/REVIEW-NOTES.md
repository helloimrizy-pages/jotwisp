# App Review notes (draft)

Jotwisp is a local-only plain-text scratchpad. No account, sign-in, subscription,
in-app purchase, remote service, or special hardware is required. No demo account
is needed. Support: rizy.izy15@gmail.com.

1. Launch the app and type in a draft. Create another with Command-N.
2. Search across drafts with Command-Shift-F. Command-F searches the current draft.
3. Copy plain text from another app. With Jotwisp running, press Control–Option–V
   and release the keys. Jotwisp opens a new draft containing the clipboard text.
   File → New Draft from Clipboard is the manual alternative. If another app
   already uses the shortcut, disable that conflict and retry setup.
4. Quit and reopen: drafts restore without a manual save.
5. Import/export through the File menu uses the system file picker.
6. Help includes offline support, privacy policy, and MIT license documents.

The App Store binary is sandboxed and registers only Control–Option–V. It does
not use the source edition's Accessibility-based shortcut. There is no keyboard
logging or background clipboard polling, and no network entitlement.
