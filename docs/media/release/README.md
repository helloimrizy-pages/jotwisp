# Jotwisp release media sources

These are real captures of the signed, sandboxed Jotwisp build (1.1.0, build 2),
using only fictional demo drafts. No personal drafts, other apps, desktop or audio
were recorded. Screenshots are native 2560 × 1600 PNG files.

Video sources are 30 fps excerpts of window-only macOS recordings, cropped to
remove window shadows and the macOS recording indicator/titlebar. The app UI is
not simulated. `scripts/app-store-preview.js` assembles the App Store preview in
Higgsfield with simple explanatory overlays and no people or device mockups.

Sources: `drafts-source.mp4` (6 s), `search-source.mp4` (12 s),
`code-source.mp4` (6 s). Original raw captures are kept locally in
`build/release-media/raw/`, outside the Git repository.

The separate logo-led launch commercial is promotional material, not a substitute
for the footage-based App Store preview. App Store acceptance remains subject to
Apple review.
